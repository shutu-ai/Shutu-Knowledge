# 0.4 Benchmark & Ablation — Current PH9 Harness

Status: deterministic 0.2/0.3/0.4 benchmark evidence is implemented and passing.
The harness uses answer-support proxies rather than an LLM judge, so final
release still requires broader answer-quality review and CI/package evidence.

## Method

The immutable 0.2 baseline was executed from a detached worktree at:

```text
tag:    v0.2.1
commit: 66d5a4fa9f05945b459235e171e7d43423eb302b
```

Its query results are persisted in
[0.4_benchmark_0.2_baseline.json](0.4_benchmark_0.2_baseline.json).

The current harness compares:

* **0.2**: immutable v0.2.1 hybrid Search;
* **0.3**: current hybrid Search and serialized context windows;
* **0.4**: `CompileKnowledgeContext`, with each query bounded to the 0.2/0.3
  token projection for that query (minimum useful budget 64).

Quality proxy:

* required-document coverage for exact evidence;
* global Topic/Summary orientation coverage for global queries;
* required fact-chain coverage for multi-hop queries;
* forbidden superseded-document selection for the temporal-current query.

Token proxy is the deterministic shared token estimator. No model provider,
network access, or human judge is required, making the regression reproducible
in CI.

The aggregate support proxy improves by 25.9% over 0.2/0.3 while aggregate
context tokens fall by 18. Global understanding and multi-hop fact-chain
coverage improve; fact, cross-document, and temporal-current support do not
regress. Cross-document quality improves at the default 2048-token budget, but
not under the current equal-token stress; it remains non-regressing there.

## Expanded corpora

* `testdata/document_intelligence`: English/Chinese Markdown, DOCX, PPTX, and
  XLSX fixtures are compiled together. The test requires one Summary per file,
  exact chunk provenance, and a global ContextPackage with evidence.
* SmartCare/telecom scenario: professional terms, `CCA_OFFSET`/`CCA_OFFSET_V2`
  version drift, KQI aggregation, N2, AMF relocation, and causal impact are
  tested. It proves version supersession and the need for bounded sequence
  relations.
* Same-version contradiction: two different values for the same version and
  attribute become `conflicted`, not active facts.
* Historical temporal query: explicit history language can recall a superseded
  fact while ordinary/current queries exclude it.
* Code knowledge scenario: API/design/storage documentation is compiled into a
  bounded causal explanation with exact chunk provenance; no full Code
  Intelligence engine is introduced.
* Restart recovery: pending semantic changes survive close/reopen and compile
  into the next generation.
* 0.3 migration: an active database is downgraded to schema 0018 semantics and
  then upgraded through migrations 0019/0020 without rebuilding chunks or
  changing chunk/generation identity.

## Ablations

| Mechanism | Observed effect |
|---|---|
| Global Topic/Summary activation | Adds hierarchy orientation unavailable to 0.2/0.3 evidence-only output. |
| Concept-title evidence query variants | Improve cross-document recall at the default budget without replacing exact Search. |
| Fact/concept derived-from chains | Improve multi-hop support while preserving exact evidence. |
| Same-node sequence relations | Enabled only after SmartCare ablation missed `N2 → AMF relocation`; bounded two-hop traversal recovers the professional causal chain. |
| Versioned supersession | Older `version 0.2` facts are excluded from current fact activation and marked with `superseded_by`. |

## Regression constraints

The harness fails if:

* routing assigns the wrong intent;
* 0.4 falls below 0.3 on any family;
* superseded `version 0.2` evidence is selected for the current query;
* ContextPackage exceeds its budget;
* aggregate 0.4 support does not exceed immutable 0.2 support;
* aggregate 0.4 tokens exceed immutable 0.2 tokens.

## Remaining benchmark gaps

* Add repeated-query reuse measurements.
* Add LLM-judged or rubric-based answer-quality scoring.
* Persist machine-readable current 0.3/0.4 results outside test logs.
* Run release race, web, migration, agent, package-smoke, push CI, and tag CI.
