# 0.4 Benchmark & Ablation — Preliminary PH9 Harness

Status: deterministic 0.3-vs-0.4 benchmark harness implemented and passing on a
four-document release/capacity/vector corpus. This is **not yet the final
release benchmark**: it uses answer-support proxies rather than LLM-judged
answer quality, does not cover the full public test corpus, and does not yet
compare a 0.2 build.

## Method

For each query family, the harness compares:

* **0.3 baseline**: the existing hybrid Search results and serialized context
  windows;
* **0.4**: `CompileKnowledgeContext` with a 2048-token budget, semantic
  orientation, semantic-derived query variants, facts, evidence, and citations.

Quality proxy:

* required-document coverage for exact evidence;
* global Topic/Summary orientation coverage for global queries;
* required fact-chain coverage for multi-hop queries;
* forbidden superseded-document selection for the temporal-current query.

Token proxy is the deterministic shared token estimator. No model provider,
network access, or human judge is required, making the regression reproducible
in CI.

## Current results

| Query family | 0.3 quality proxy | 0.4 quality proxy | 0.3 tokens | 0.4 tokens |
|---|---:|---:|---:|---:|
| Fact | 1.000 | 1.000 | 135 | 449 |
| Global | 1.000 | 2.000 | 135 | 620 |
| Cross-document | 0.500 | 1.000 | 41 | 576 |
| Multi-hop | 1.000 | 1.500 | 102 | 349 |
| Temporal current | 1.000 | 1.000 | 41 | 157 |
| **Aggregate** | **4.500** | **6.500** | **454** | **2,151** |

The 0.4 aggregate support proxy improves by 44.4%. Global understanding,
cross-document coverage, and multi-hop fact-chain coverage improve; exact fact
and temporal-current support do not regress.

Context tokens are currently higher, not lower. The current success evidence is
knowledge internalization/support quality, not token efficiency. The final
release gate still needs an equal-answer-quality/equal-token comparison and a
stronger corpus.

## Ablations represented by implementation

| Mechanism | Observed effect |
|---|---|
| Global Topic/Summary activation | Global proxy rises from 1.000 to 2.000 because hierarchical orientation is available in addition to evidence coverage. |
| Concept-title evidence query variants | Cross-document proxy rises from 0.500 to 1.000 by expanding exact Search with activated Concept/Topic titles. |
| Fact/concept derived-from chains | Multi-hop proxy rises from 1.000 to 1.500 by carrying both chain facts into ContextPackage. |
| Relation edges | Not enabled. No current ablation proves a relation table is needed beyond the deterministic Fact→Concept→Topic chain. |

## Regression constraints

The harness fails if:

* routing assigns the wrong intent;
* 0.4 falls below 0.3 on any family;
* superseded `version 0.2` evidence is selected for the current query;
* ContextPackage exceeds its budget;
* aggregate 0.4 support does not exceed 0.3.
