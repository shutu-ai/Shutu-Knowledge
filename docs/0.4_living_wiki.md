# 0.4 Living Wiki — PH7

Status: deterministic Wiki view rendering implemented over the active semantic
compilation. The Wiki is a projection, not a data model, and it is rebuilt from
KnowledgeUnits without touching evidence.

## Boundary

```text
KnowledgeUnits
    ↓ deterministic renderer
WikiView / WikiPage / Markdown
```

The rendered Markdown explicitly states:

> Generated Wiki view. Edit the source documents and recompile; this page is
> not authoritative evidence.

No user editing state is mixed into PH7. A future editor must separate
generated and user-authored content rather than mutating compiled units.

## Page model

A `WikiPage` contains:

* deterministic generation-scoped ID;
* title;
* summary;
* concept sections;
* concept and fact unit IDs;
* related page IDs;
* exact evidence closure;
* semantic generation.

A `WikiView` records:

* semantic generation;
* renderer version `wiki-view-v1`;
* regenerable=true;
* pages.

Topic pages are rendered when Topics exist. If a small corpus has Concepts but
no Topics, concepts become standalone pages; the renderer does not invent an
ontology.

## Regeneration and provenance

`Service.GetSemanticWiki(baseID)` loads the active immutable compilation and
renders the view on demand. Recompiling after an update/delete produces a new
generation and new deterministic view. Original documents, IR nodes, chunks,
and citations are never modified.

Every page follows its Topic → Concept → Fact → IR/chunk `derived_from` chain.
Markdown source evidence includes:

* document ID;
* immutable index generation;
* source version;
* IR node ID;
* chunk ID.

Related pages are derived only from shared Fact unit support, not from a graph
service or inferred similarity.

## Verified properties

* deterministic output for the same compilation;
* no page without exact evidence;
* generated-content boundary in Markdown;
* concept fallback without fabricated Topics;
* shared-fact related-page links;
* source evidence in every rendered page.

## Remaining limits

* The view is read-only and exposed through `/semantic/wiki`; manual editing and
  revision history remain deferred.
* Pages are read-only and regenerated; revision history/manual editing is
  deferred beyond 0.4 unless explicitly reinstated by a release decision.
* Relations are not rendered because compiler v0 emits no semantic relation
  edges yet.
