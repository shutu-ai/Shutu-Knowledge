# 0.4 Real-World Error Taxonomy

This taxonomy is derived from the 119-query real-world validation run and is
deliberately separated from final LLM answer errors.

## E1 Retrieval Miss

- **Observed:** yes.
- **Evidence:** 17 per-query regressions; several corpus-A temporal and global
  queries selected the wrong release/building document.
- **Impact:** medium-high.
- **Boundary:** this is not automatically a compiler defect; context selection
  and query routing must be checked first.

## E2 Knowledge Extraction Error

- **Observed:** yes, but bounded.
- **Evidence:** the 3GPP corpus produced only 2 concepts and 2 topics from two
  very large specifications.
- **Impact:** high for global/spec questions.
- **Boundary:** the deterministic compiler is intentionally conservative; this
  is an abstraction gap, not proof of hallucination.

## E3 Wrong Concept Merge

- **Observed:** yes.
- **Evidence:** 74 duplicate canonical keys across corpora (A=44, B=2, C=28).
- **Impact:** medium.
- **Boundary:** duplicate canonical keys are not necessarily wrong merges, but
  they indicate normalization/dedup noise.

## E4 Relation Hallucination

- **Observed:** no.
- **Evidence:** all sampled relations retained provenance; no invalid relation
  provenance was found.
- **Impact:** low.
- **Boundary:** 0.4 only emits conservative adjacent sequence relations, so this
  does not prove general relation extraction is safe.

## E5 Summary Distortion

- **Observed:** no empty/unsupported summaries.
- **Evidence:** 0 empty summaries and 0 invalid provenance in the audit.
- **Impact:** low.
- **Boundary:** semantic fidelity of summaries still needs expert review.

## E6 Version Confusion

- **Observed:** yes.
- **Evidence:** TEMPORAL fell from 0.917 to 0.861; all four Open5GS temporal
  probes regressed.
- **Impact:** high.
- **Boundary:** the failure is mostly context selection between release notes,
  not semantic storage corruption.

## E7 Query Routing Error

- **Observed:** not directly isolated.
- **Evidence:** routing was recorded through the AUTO path, but the harness did
  not perform a routing-only ablation.
- **Impact:** unknown.
- **Boundary:** do not redesign routing without a routing-only ablation.

## E8 Context Selection Error

- **Observed:** yes.
- **Evidence:** corpus-A GLOBAL document coverage was 0.083; some 0.4 packages
  selected fewer/different documents than 0.3 despite a similar token budget.
- **Impact:** high for global understanding.
- **Boundary:** this is the strongest near-term architecture gap.

## E9 Citation Error

- **Observed:** no.
- **Evidence:** citation coverage was 1.000 and unsupported claims were 0.
- **Impact:** none observed.

## E10 LLM Answer Error

- **Observed:** not measurable in this run.
- **Evidence:** no answer LLM or LLM judge was attached.
- **Boundary:** final answer quality requires a fixed model and judge; this run
  intentionally did not claim that evidence.
