## Key Failures

1. **Temporal/version confusion on release notes.** 0.4 regressed on four
   Open5GS release queries because lexical concept expansion could not reliably
   prefer the requested version.
2. **Weak global abstraction on real product docs.** The GLOBAL category was
   the weakest area, with only 0.083 document coverage on corpus A global
   queries.
3. **Concept starvation on large specifications.** TS 23.501/23.502 produced
   almost no useful concepts/topics, reducing semantic orientation value.
4. **Duplicate canonical knowledge.** 74 duplicate canonical keys were observed
   across the three corpora, indicating normalization/merge noise.

## 0.5 Candidates

1. **Temporal/version-aware context selection** - high user impact, directly
   evidenced by the temporal regression.
2. **Global briefing / domain abstraction** - evidenced by weak GLOBAL coverage
   and sparse concept/topic generation on large documents.
3. **Context-selection tuning for very large documents** - evidenced by high
   3GPP latency and chunk count, but lower priority than the two correctness
   items above.

## Recommendation

```text
START 0.5 WITH SPECIFIC GAP
```

Start with temporal/version-aware context selection. Treat global briefing as
the second candidate. Do not start GraphRAG, a new storage engine, or a general
ontology without additional evidence.
