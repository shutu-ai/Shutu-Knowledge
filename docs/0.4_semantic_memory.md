# 0.4 Semantic Memory Retrieval — PH4

Status: deterministic Concept/Topic/Summary activation implemented over the
active immutable compilation. It is an additional lane beside the existing 0.3
hybrid Evidence Memory; it does not replace BM25/vector/RRF/rerank/MMR.

## API shape

`Service.SearchSemanticMemory(baseID, semantic.SearchOptions)` requires an
active semantic compilation and returns:

* normalized query and lexical activation terms;
* requested unit kinds;
* generation, scoring version, and deterministic routing plan;
* ranked semantic hits;
* each unit's full exact evidence closure.

The default kinds are:

```text
concept
topic
summary
```

Facts can be requested explicitly for ablation or later context assembly, but
are not returned by default. `knowledge_page` is accepted by the primitive but
is not generated until the Living Wiki phase.

## Activation scoring

PH4 uses deterministic offline `lexical-v1` scoring:

* title match: 4 points per term;
* alias/canonical-key match: 3 points per term;
* content match: 1 point per term;
* query coverage multiplies the raw score;
* exact normalized phrase match adds a bounded bonus;
* a small provenanced-dependency bonus breaks quality ties toward units with
  stronger support.

Latin words are tokenized as words. CJK runs use deterministic bigrams (or a
single rune for a one-character query). Results are sorted by score, coverage,
unit-kind priority, then canonical key. Global intents additionally activate
the strongest Topic/Summary hierarchy even when the query has no lexical title
overlap. The implementation therefore gives the same output for the same
compilation and query without a model call.

## Evidence boundary

A semantic hit is never reported as an evidence chunk. The response carries:

```text
activated semantic unit
    ↓ derived_from closure
exact Document IR node / existing chunk / document generation / source version
```

Tests reject hits without an evidence closure and reject provenance that has
neither an IR node nor chunk. This preserves 0.3 citation authority while
adding conceptual activation.

## Degradation

* No active semantic compilation returns `ErrNotFound`; 0.3 search remains
  available.
* A deleted base is not searchable.
* No model, external vector service, graph service, or network access is
  required.
* Existing Search is unchanged before and after compilation.

## Remaining limits

* PH4 activation is lexical; embedding-backed semantic-unit search is deferred
  until it demonstrates benchmark value.
* Semantic hits are not yet merged into the final LLM context package.
* Query routing and fact/global/cross-document/multi-hop/temporal modes are
  later phases.
* Relation expansion is deferred to the benchmark-gated lightweight graph phase.
