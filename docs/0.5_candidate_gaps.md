# 0.5 Candidate Gaps

These candidates are generated from the 119-query real-world validation run.
They are not commitments and no 0.5 implementation is included here.

## 1. Temporal/version-aware context selection

- **Observed failure:** TEMPORAL support fell from 0.917 to 0.861; all four
  Open5GS release probes regressed.
- **User impact:** high; users asking about the current version may receive an
  older release's behavior.
- **Potential gain:** high.
- **Complexity:** medium.
- **Runtime cost:** low-to-medium.
- **Storage cost:** low.
- **Token cost:** neutral-to-lower.
- **Compatibility risk:** low if release/version metadata stays additive.
- **Recommendation:** highest-priority 0.5 candidate.

## 2. Global briefing / domain abstraction

- **Observed failure:** GLOBAL support improved only to 0.731 and corpus-A
  global document coverage was 0.083. Large specifications produced almost no
  concepts/topics.
- **User impact:** high for “what does this corpus cover?” questions.
- **Potential gain:** high.
- **Complexity:** medium-high.
- **Runtime cost:** medium.
- **Storage cost:** medium.
- **Token cost:** can be neutral if summaries replace repeated evidence.
- **Compatibility risk:** low if compiled as another projection.
- **Recommendation:** second candidate; keep it as briefing/abstraction, not
  GraphRAG.

## 3. Context-selection tuning for very large documents

- **Observed failure:** TS 23.501/23.502 produced 113,950 chunks and 0.4 latency
  rose to roughly 2.5 seconds per query.
- **User impact:** medium-high on large spec corpora.
- **Potential gain:** medium.
- **Complexity:** medium.
- **Runtime cost:** potentially lower after tuning.
- **Storage cost:** unchanged.
- **Token cost:** neutral.
- **Compatibility risk:** low.
- **Recommendation:** third candidate; only pursue after temporal/global gaps.

## Not justified by current evidence

- GraphRAG
- New storage architecture
- New vector database
- General ontology engine
- Autonomous knowledge maintenance
- Memory consolidation as a large subsystem
