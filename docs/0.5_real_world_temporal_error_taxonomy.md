## Primary error pattern

Ambiguous temporal range/history reasoning is the top gap. The repeated
“earlier Open5GS release stages” query returned two non-release documents and
omitted the expected historical release evidence in all eight repetitions. This
is a routing/context-range gap, not evidence corruption.

## Secondary error pattern

Current resolution is brittle when several documents mention the same product
but only one is current. The compiler usually knows the version boundary, but
retrieval can promote a generic page or an unrelated report above the current
anchor.

## Safety boundary

A selection miss must not become knowledge corruption. The audit found no false
supersession, no fabricated temporal metadata, and no invalid audited temporal
provenance.
