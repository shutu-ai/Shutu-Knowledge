# Shutu Knowledge 0.2.1

Windows Tier-1 release with a local managed Runtime.

- PDF, Office, and OCR ingestion
- Embedding and Hybrid Retrieval
- Reranker and citation support
- Shutu-Agent integration
- Durable operation and restart recovery
- Portable Windows x64 package

Deferred from 0.2:

- Linux full release-host validation
- macOS full release validation
- Extreme-scale validation
- Document Intelligence / Document IR

The 0.2.x line is now in maintenance mode. Bugfixes, security fixes, data
integrity fixes, compatibility fixes, and packaging fixes are accepted. New
capabilities and architecture work are planned for 0.3.
