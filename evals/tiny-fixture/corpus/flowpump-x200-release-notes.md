# FlowPump X200 Release Notes

## Version 1.2

Version 1.2 supports a maximum pressure of 6 bar and introduces the eco mode.
Eco mode reduces energy use by roughly 12 percent.

## Version 1.3

Version 1.3 raises the maximum pressure to 8 bar.
Eco mode in version 1.3 adds an automatic night setback between 22:00 and 06:00.
Version 1.3 removes the annual gasket swap requirement.
